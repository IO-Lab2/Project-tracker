STRUCTURE DESCRIPTION
docs/ - general description of the inner workings of the scraper
scraper/ - source code directory
scraper/scrapy.cfg - config for scrapy
scraper/constants.py - constants for the whole repository
scraper/knowledge_scraper/ - scrapy project files
scraper/utils/ - helper modules which are universal within the entire project
scraper/scripts/ - helper modules which serve a more specific purpose
scraper/other/ - other files

scrapy automatically adds directory with scrapy.cfg to sys.path so packages in scraper/ directory can import each other.

We want to check any relationships between items in the database.
If first item references a second item. Then they should be sent to pipelines in order: second -> first.
											before    later

note on organizations:
organizations should be returned in order: parent -> child
universities must have parent_id == None
organizations have different types on pb website and in the database
